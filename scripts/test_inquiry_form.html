IEA Inquiry Form Simulator

Posts to crm.api.web_lead.capture_inquiry exactly as the website's backend would.

Local testing only. This page puts the API key in the browser, which the real integration must never do. On the live site the key stays on your server: the browser posts to your backend, your backend checks the captcha and then calls the CRM with the key. That is also why this endpoint sends no CORS headers — opening this file straight from disk (file://) will be blocked by the browser. Serve it over http instead: python3 -m http.server 8080, then open http://localhost:8080/scripts/test_inquiry_form.html.
